# Senai-primeira-fase

Este repositório contém uma coleção de exercícios, projetos e materiais de apoio desenvolvidos durante o 1 semestre do curso no SENAI. O objetivo deste projeto é registrar a evolução do aprendizado em lógica de programação e desenvolvimento web.

## 📁 Estrutura do Repositório

O repositório está organizado por pastas, abrangendo diferentes tópicos estudados:

- **Dom-exercicios**: Exercícios focados na manipulação do Document Object Model (DOM).
- **aula-de-if-else / aula-javascript-Luciano**: Exercícios e exemplos sobre estruturas condicionais.
- **aula-portugol**: Introdução à lógica de programação utilizando Portugol.
- **crud**: Implementação de operações básicas de CRUD (Create, Read, Update, Delete).
- **logica-js**: Prática de lógica de programação utilizando JavaScript.
- **repeticoes / repticoes**: Exercícios focados em estruturas de repetição (loops).
- **sq02 / sq05**: Exercícios de fixação e desafios propostos.
